Kebijakan Privasi

rclone-rekap · Terakhir diperbarui 16 Oktober 2026

Ringkasan

Aplikasi ini bersifat lokal dan pribadi. Data transaksi Anda tetap berada di perangkat Anda, dengan salinan backup yang hanya dikirim ke akun Telegram dan Google Drive milik Anda sendiri. Tidak ada data yang dijual, dibagikan, dianalisis, atau dikirim ke server pihak ketiga.

1. Izin Google yang diminta

Aplikasi meminta satu cakupan (scope) OAuth Google:

  • https://www.googleapis.com/auth/drive — akses penuh ke Google Drive

Dengan izin tersebut, aplikasi hanya melakukan satu hal: mengunggah file backup (XLSX/ZIP) ke folder backup milik Anda di Google Drive. Tidak ada file lain yang dibaca, diubah, dipindahkan, maupun dihapus. Token otorisasi disimpan di perangkat Anda dan tidak dibagikan.

2. Data yang diproses

  • Data transaksi yang Anda masukkan sendiri (via tempel/unggah CSV): tujuan, serial number, produk, status, nama reseller, harga, laba, saldo.
  • Metadata teknis minimal yang dibutuhkan untuk proses backup (waktu pengiriman, nama file).

Tidak ada data pribadi pengunjung yang dikumpulkan, karena halaman ini tidak memiliki analitik, pelacakan, maupun cookie.

3. Penyimpanan

  • Lokal — basis data SQLite di perangkat yang menjalankan aplikasi.
  • Google Drive — file backup di folder backup milik Anda.
  • Telegram — salinan XLSX ke channel pribadi Anda.

4. Pembagian data

Data Anda tidak dibagikan kepada pihak ketiga mana pun, tidak dijual, dan tidak digunakan untuk tujuan periklanan atau pemodelan.

5. Penghapusan

Anda dapat menghapus data kapan saja: hapus isi basis data lokal melalui aplikasi, kosongkan folder backup di Google Drive, dan/atau hapus pesan backup di Telegram. Memotong izin aplikasi dapat dilakukan kapan saja melalui Google Account → Aplikasi pihak ketiga.

6. Perubahan

Kebijakan ini dapat diperbarui. Tanggal pembaruan terakhir selalu dicantumkan di atas.
